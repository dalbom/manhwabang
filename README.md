# 만화방

iPhone 홈 화면에 추가해 쓰는 EPUB·만화(ZIP, CBZ) 리더 웹앱입니다.

**https://dalbom.github.io/manhwabang/**

이 저장소에는 GitHub Pages로 내보내는 빌드 결과물만 있습니다.

## 설치

1. iPhone의 Safari로 위 주소를 엽니다.
2. 공유 버튼 → "홈 화면에 추가"를 누릅니다.
3. 홈 화면의 아이콘으로 앱을 열고 비밀번호를 정한 뒤, 파일 앱에서 책을 가져옵니다.

## 알아 둘 것

- 서버가 없습니다. 가져온 책과 읽은 기록은 그 기기 안에만 저장되고 어디로도 보내지 않습니다. 앱은 실행 중에 외부 주소로 요청을 보내지 않습니다.
- 처음 연 뒤에는 인터넷 없이도 열립니다.
- 홈 화면에서 아이콘을 지우면 책과 기록도 지워집니다. 설정 → 백업으로 가끔 백업해 두세요.
- 가져오는 파일을 읽고 이용할 권리가 있는지는 사용자가 확인해야 하며, 파일의 저작권과 라이선스에 대한 책임은 사용자에게 있습니다.
- 새 버전은 저절로 적용되지 않습니다. 앱 안에서 바뀐 점을 보고 적용할지 고릅니다.
- 이 앱은 있는 그대로 제공되며 어떤 보증도 하지 않습니다. 함께 배포하는 오픈소스와 글꼴의 라이선스는 앱의 설정 → 앱 정보에서 볼 수 있습니다.
