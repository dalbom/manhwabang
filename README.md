# 만화방

iPhone 홈 화면에 추가해 쓰는 EPUB·만화(ZIP, CBZ) 리더 웹앱입니다.

**https://dalbom.github.io/manhwabang/**

이 저장소에는 GitHub Pages로 내보내는 빌드 결과물만 있습니다.

## 설치

1. iPhone의 Safari로 위 주소를 엽니다.
2. 공유 버튼 → "홈 화면에 추가"를 누릅니다.
3. 홈 화면의 아이콘으로 앱을 열고 비밀번호를 정한 뒤, 파일 앱에서 책을 가져옵니다.

## 알아 둘 것

- 서버가 없습니다. 가져온 책과 읽은 기록은 그 기기 안에만 저장되고 어디로도 보내지 않습니다. 앱은 실행 중에 외부 주소로 요청을 보내지 않습니다.
- 처음 연 뒤에는 인터넷 없이도 열립니다.
- 홈 화면에서 아이콘을 지우면 책과 기록도 지워집니다. 설정 → 백업으로 가끔 백업해 두세요.
- 가져오는 파일을 읽고 이용할 권리가 있는지는 사용자가 확인해야 하며, 파일의 저작권과 라이선스에 대한 책임은 사용자에게 있습니다.
- 새 버전은 저절로 적용되지 않습니다. 앱 안에서 바뀐 점을 보고 적용할지 고릅니다.
- 이 앱은 있는 그대로 제공되며 어떤 보증도 하지 않습니다. 함께 배포하는 오픈소스와 글꼴의 라이선스는 앱의 설정 → 앱 정보에서 볼 수 있습니다.

## 바뀐 점

지금 버전: `202611240842-1ca0b19d`

### 2026년 11월 24일

- TXT 파일도 넣을 수 있습니다. "제1장", "1화" 같은 줄로 목차를 만들고, 옛 윈도우 인코딩(CP949) 파일도 글자가 깨지지 않습니다.
- 안드로이드 크롬에서도 앱으로 설치할 수 있게 했습니다(시험 중).
- 갤럭시 폴드처럼 펼치는 폰을 펴면 만화는 좌우에 한 쪽씩, EPUB은 두 단으로 보입니다.
- 만화의 두 쪽 보기와 EPUB의 두 단 보기 설정 이름을 "넓은 화면에서"로 바꿨습니다.
- 쪽이 많은 만화도 처음 열 때 오래 기다리지 않습니다. 읽던 쪽부터 바로 보이고, 나머지 쪽 정보는 읽는 동안 뒤에서 읽습니다.
- 안드로이드에서 보기 설정 같은 창의 아래쪽 내용이 창 모서리 밖으로 튀어나오던 문제를 고쳤습니다.
- 안드로이드에서 책을 가져오거나 백업 파일을 저장할 때, 파일 고르는 창을 다녀와도 다시 비밀번호를 묻지 않습니다.
- 안드로이드에서 뒤로 가기를 하면 열린 창이나 앞 화면이 닫힙니다. 서재 첫 화면에서만 앱이 닫힙니다.
- 일부 기기에서 책갈피로 옮겨 가면 한 쪽 앞이 열리던 문제를 고쳤습니다.

### 2026년 10월 14일

- 새 버전이 나와도 바로 바뀌지 않습니다. 바뀐 점을 보고 적용할지 고를 수 있습니다.
- 설정 → 앱 정보에서 버전, 가져온 파일에 대한 안내, 오픈소스 라이선스를 볼 수 있습니다.
- 앱 이름을 "만화방"으로 바꾸고 기본 아이콘을 새로 그렸습니다.

### 2026년 10월 13일

- 화면 위쪽 상태 표시줄 자리에 본문이 겹쳐 흐려지던 문제를 고쳤습니다.
- 백업은 기본으로 읽은 기록만 담습니다. 책을 다시 가져오면 보관해 둔 기록이 자동으로 붙습니다.
- 백업 파일의 기본 크기를 2GB로 늘리고, 저장 옆에 내려받기를 늘 함께 둡니다.
